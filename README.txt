German–Arabic Stories Website

Open german_arabic_stories_website.html in Chrome/Edge/Firefox.

Features:
- 4 story tabs
- German + Arabic paragraph cards
- automatic Arabic translation with browser-side online fallback and local caching
- German TTS; prefers Google German/de-DE browser voice when available
- Done checkbox automatically collapses completed paragraphs
- Dark and Sepia themes
- General German↔Arabic translation tab
- Local progress persistence via localStorage

Internet is needed only for paragraphs that have not yet been translated/cached and for general translation.
